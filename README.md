# Лабораторная работа № 2

Одномерный статический массив из 100 целых чисел: сортировка, поиск и обмен элементов.

## Сборка и запуск

Windows, MinGW (g++), C++17. Команды для PowerShell:

```powershell
g++ -std=c++17 -fexec-charset=CP1251 lab2.cpp -o lab2.exe
.\lab2.exe
```

## Индивидуальное задание № 4

Циклический сдвиг вправо на `K` позиций и сумма элементов с индексами `0, 2, 4, …`. Индексы отсчитываются с нуля. В задании № 4 основного блока среднее минимума и максимума округляется до целого.
